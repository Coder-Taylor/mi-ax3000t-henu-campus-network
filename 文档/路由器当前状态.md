> **硬件版本判定**：`dmesg` 里出现 `an8855-switch ... Link is Up` 和
> `mt7530-mdio ... probe failed` 同时存在 = V2。那句 mt7530 探测失败在 V2 上是正常的
> （DTS 同时声明了两个 switch 节点）。
>
> V2 内部按 NAND 厂商再分批：ESMT（≥23.05.4）/ Winbond（≥24.10.1）/ Foresee（≥24.10.3）。
> 另有 RD03v2 = 高通 IPQ5018，和 MT7981 版固件**互不通用**。

### 网络拓扑

```
  henu-student（校园网 WiFi，5GHz，ch149，信号 -48dBm）
       │
       │  5G STA (phy1-sta0)，HE 80MHz，协商速率 960/1200Mbit

  ┌────────────────────────┐
  │      AX3000T           │

  └───┬────────────┬───────┘
      │            │

      │            │
   笔记本/新手机   旧手机/IoT
```

### 接口

| 接口 | 类型 | 用途 | 状态 |
|---|---|---|---|
| `phy1-sta0` | 5G STA | WAN，连 henu-student | 已连接 |
| `phy1-ap0` | 5G AP | LAN 热点 | ch52 / HE40 |
| `phy0-ap0` | 2.4G AP | LAN 热点 | ch1 / HE20 |
| `br-lan` | 桥接 | 有线 + 无线 | 192.168.1.1/24 |
| `wg0` | WireGuard | VPN 客户端 | 10.66.66.2/24 |
| `ifb4phy1-sta0` | 虚拟 | CAKE 下行队列 | — |

### 无线参数

| 参数 | 2.4G | 5G | 为什么这么设 |
|---|:---:|:---:|---|
| 加密 | WPA2-PSK | WPA2-PSK | 兼容性最好 |
| `disassoc_low_ack` | 0 | 0 | 关掉弱 ACK 踢出，防连锁断联 |
| `skip_inactivity_poll` | 1 | 1 | 不发探测帧，省管理开销 |
| `max_inactivity` | 86400 | 86400 | 24 小时才判空闲（默认 300 秒会踢掉息屏手机） |
| `uapsd` | 0 | 0 | 关省电模式，避免唤醒延迟 |
| `auth_cache` | 1 | 1 | PMKSA 缓存，加速重连 |
| `wpa_group_rekey` | 86400 | 86400 | 组密钥 24 小时更新一次 |
| DHCP 租约 | 168h | — | 7 天，消除 12 小时断联阈值 |
| STA `powersave` | — | 0 | WAN 侧不用省电 |

> `max_inactivity` 和 `wpa_group_rekey` 需要重启 wireless 才生效。
> **不要用 `wifi reload` 热重启**——满流量时会触发内核崩溃。等每周一/周四 4:00 的自动重启。

### CAKE 流控

```
sqm.eth1 接口 phy1-sta0 / ifb4phy1-sta0
cake / piece_of_cake.qos
带宽 110000 kbit（上下行同值）
nat dual-srchost triple-isolate wash ack-filter
overhead 44，linklayer ethernet
```

实测：满速下载时 ping 从 23.1ms 涨到 25.7ms（**+2.6ms**），0 丢包。

> 110Mbit 是实测峰值（单流 66Mbit，多流接近 110Mbit）的约 90%。
> 改这个值见 [日常使用.md](日常使用.md)。

### 闪存分区

```
mtd0:  1MB    BL2          启动引导（刷机不能碰）
mtd1:  256KB  Nvram
mtd2:  256KB  Bdata
mtd3:  2MB    Factory      WiFi 校准数据（最宝贵）
mtd4:  2MB    FIP          U-Boot + ATF（刷机不能碰）
mtd5-7:       crash/KF     日志区，pstore 用这里
mtd8:  34MB   ubi_kernel   内核 + squashfs
mtd9:  78MB   ubi          overlay，约 58MB 可用
```

> pstore 只有 4 块位。满了会显示 `(dmesg-ramoops-N: ENOSPC)`，新崩溃记录存不进去。
> 清理：`rm -f /sys/fs/pstore/*`。

## 两台共存注意

笔记本同时"网线接 .2 + WiFi 连 .1"时会有两条默认路由，Windows 按 metric 选（通常走 WiFi）。
改配置前先确认连的是哪一台：

```bash
ssh ax3000t "hostname; ip -4 addr show br-lan | grep inet"    # 192.168.1.1
ssh ax3000t2 "hostname; ip -4 addr show br-lan | grep inet"   # 192.168.1.2
```
