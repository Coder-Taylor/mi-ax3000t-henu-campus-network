| | 自用机（旧） | 部署机（2026-10-09，待售） |

| 管理地址 | `192.168.1.1`（`ssh ax3000t`） | **`192.168.1.2`**（`ssh ax3000t2`） |
| 硬件 | V2：MT7981 + **AN8855** 交换机 | V2：MT7981 + **AN8855** 交换机 |
| 闪存 | ESMT SPI-NAND 128MiB | **Winbond** SPI-NAND 128MiB |
| 系统 | ImmortalWrt 24.10.5 | ImmortalWrt 24.10.5 |

> **硬件版本判定**：dmesg 出现 `an8855-switch ... Link is Up` + `mt7530-mdio ... probe failed` = **V2**
> （V2 上那句 mt7530 探测失败是正常现象，DTS 同时声明了两个 switch 节点）。
> V2 内部按 NAND 厂商分批：ESMT（≥23.05.4）/ Winbond（≥24.10.1）/ Foresee（≥24.10.3）。
> 社区另有 RD03v2 = 高通 IPQ5018 版本，与 MT7981 版固件**互不通用**。

## WiFi hostapd 调优 (Phase 13)

| 参数 | 2.4G (phy0-ap0) | 5G (phy1-ap0) | 说明 |
|------|:---:|:---:|------|
| `disassoc_low_ack` | 0 | 0 | 关闭弱ACK踢出，防连锁断联 |
| `skip_inactivity_poll` | 1 | 1 | 跳过不活跃探测，减少管理帧 |
| `wpa_group_rekey` | 86400 | 86400 | 组密钥更新间隔 24h |
| `uapsd_advertisement_enabled` | 0 | 0 | 关闭 WMM 省电模式 |
| `disable_pmksa_caching` | (无=开启) | (无=开启) | PMKSA 缓存加速重连 |
| DHCP 租约 | 168h | — | 7天，消除 12h 断联阈值 |

## 故障排查

| 问题 | 命令 |
|------|------|
| 认证失败 | `cat /tmp/campus_network.log` |
| 手动认证 | `/etc/campus_network/auto_login.sh` |
| 校园内部网站打不开 | `sh /etc/campus_network/dns_fix.sh` |
| 守护进程状态 | `ps \| grep fast_recovery` |
| 启动后断网 | 守护进程 v2.0 自动等待 + 30秒冷却期 |
| WiFi断开 | `wifi reload` |
| 查看连接 | `iw dev phy1-sta0 link` |
| 查看IP | `ip addr show dev phy1-sta0` |
| 测试外网 | `ping 223.5.5.5`（**8.8.8.8/114 被校园网屏蔽 ICMP**，用它们会误判断网） |
| 认证会话过期 | HTTP 被劫持但 ping 仍通 → 守护进程 60 秒内自动重认证；手动 `/etc/campus_network/auto_login.sh --force` |
| cron 是否在跑 | `ps \| grep [c]rond`（**crontab 里严禁写 `@reboot`**：busybox crond 不支持，会导致 crond 崩溃 + `*/5` 兜底失效） |
| 开机认证是否执行 | `grep BootAuth /tmp/campus_network.log`（由 `/etc/init.d/campus_auth` → `boot_auth.sh` 负责） |
| 查看流控 | `tc -s qdisc show dev phy1-sta0` |
| 恢复出厂 | `firstboot` 然后重启 |
| WireGuard 状态 | `wg show` |
| VPN 连通性 | `ping 10.66.66.1` |
| NTP 同步 | `date` + `logread \| grep ntp` |
| 流量统计 | LuCI → Services → Bandwidth Monitor |
| 性能图表 | LuCI → Statistics → Graphs |
