# 日常使用手册

路由器已经刷好、跑起来了。这份文档只讲"平时要动它的时候怎么做"，
不讲原理，不讲刷机。原理看 [原理详解.md](原理详解.md)。

---

## 最重要的一条：怎么连上路由器

三种进入方式，任选一种：

| 方式 | 地址 | 什么时候用 |
|---|---|---|
| 浏览器 | `http://192.168.1.1` | 改 WiFi、看流量、装插件。最直观 |
| SSH | `ssh root@192.168.1.1` | 跑脚本、看日志。改配置效率高 |
| 手机 LuCI | 同上，手机浏览器也能开 | 临时看一下状态 |

后台账号是 `root`，密码是刷机第 7 步你自己设的那个。

> 如果你设过 SSH 密钥，`ssh ax3000t` 就能免密登录，不用打 IP。

## 首次接入校园网

刷完机是空的，要配四件事：让 5G 射频去连校园网、建 WAN 接口、配防火墙、部署认证脚本。

这部分有现成的一键脚本，**不用手打命令**：

```bash
# 在电脑上，把脚本传进路由器
cd 一键配置脚本
scp auto_config.sh root@192.168.1.1:/tmp/

# 登录路由器执行
ssh root@192.168.1.1
sh /tmp/auto_config.sh
```

脚本会依次问你：root 密码、宿舍 WiFi 名和密码、校园网 SSID、学号、校园网密码、
运营商后缀、校编码。跟着提示填。

**校编码填什么**：`07cdfd23373b17c6b337251c22b7ea57`。
这是河南大学的学校编号，所有学生都一样，不是你的学号，也不含个人信息。

**运营商后缀**：移动 `@henuyd`，联通 `@henult`，电信 `@henudx`。
目前实测只有 `@henuyd` 稳定可用。

**跑完怎么确认成功**：

```bash
iw dev phy1-sta0 link            # 应该显示 Connected to henu-student
ip addr show dev phy1-sta0       # 应该有 10.x.x.x 的 IP
ping -c 3 223.5.5.5              # 应该通
```

> ⚠️ 测外网用 `223.5.5.5`。**不要用 `8.8.8.8` 或 `114.114.114.114`**——
> 校园网屏蔽了这两个地址的 ICMP，永远 ping 不通，会让你误判"网断了"。

## 改 WiFi 名称或密码

> ⚠️ **只改宿舍热点，别碰连校园网的那个接口。**
> 在 LuCI →「网络 → 无线」里，你会看到好几个接口并排。`henu-student` 那个是路由器
> **去连校园网**用的，给它设密码会导致整台路由器上不了网，宿舍所有设备一起断。
> 只要看到 SSID 是 `henu-student`，一律不要编辑。

要改的是这两个：

| 配置名 | 是什么 |
|---|---|
| `default_radio0` | 2.4G 热点（给旧手机、IoT） |
| `wifinet0` | 5G 热点（给笔记本、新手机） |

最省事的方法：浏览器打开 `http://192.168.1.1` → 网络 → 无线 →
点 `default_radio0` 或 `wifinet0` 的"编辑" → 基本设置改 SSID，无线安全改密码 → 保存并应用。

命令行等价操作：

```bash
# 2.4G 热点
uci set wireless.default_radio0.ssid='新的名字'
uci set wireless.default_radio0.key='新的密码'

# 5G 热点
uci set wireless.wifinet0.ssid='新的名字-5G'
uci set wireless.wifinet0.key='新的密码'

uci commit wireless
wifi reload
```

**先确认一下这两个名字对不对**（不同部署可能不一样）：

```bash
uci show wireless | grep -E "mode='ap'|ssid="
```

只改 `mode='ap'` 的那些。`mode='sta'` 的那个是连校园网的，绝对不能动。

> `wifi reload` 会让所有设备短时间掉线再重连，几秒钟。改完通知一下室友。
> 但**下载或看视频时不要执行** —— 满流量时它会让这台机器的内核崩溃、整机重启。
> 只有断开状态下执行才安全。

## 改校园网密码 / 换账号

校园网账号密码写在认证脚本里，改两个变量就行：

```bash
vi /etc/campus_network/auto_login.sh
```

找到文件开头这几行：

```sh
USERNAME="学号"
PASSWORD="密码"
OPERATOR_SUFFIX="@henuyd"
```

改完保存退出（`vi` 里按 `Esc`，输入 `:wq` 回车），然后立刻手动认证一次验证：

```bash
/etc/campus_network/auto_login.sh --force
tail -20 /tmp/campus_network.log
```

日志里出现 `认证成功` 就对了。

> **改完要确认第三步成功了。** 认证分三步，只有第三步（quickauth）是决定性的。
> 前两步即使失败也可能"看起来通过"，别被骗。

## 加一台新设备

不用做任何事。连上 WiFi，自动拿 IP，自动能上网。

DHCP 租期设的是 168 小时（7 天），设备短期离开回来会快速续租，不会重新走一遍完整协商。

## 看谁在用带宽

浏览器 → 服务 → 带宽监控（Bandwidth Monitor）。

按设备、按协议分开统计，每 30 秒刷新一次。能看到某台手机正在跑视频，
或者某台电脑在下载。

命令行看实时总量：

```bash
ifconfig phy1-sta0 | grep -E 'RX|TX'
```

> 注意：**开着硬件流量卸载时，接口计数器不准**（数字偏小甚至不动）。
> 想知道真实流量用 LuCI 的带宽监控，那个统计在 NAT 之前。

## 看网络质量历史

浏览器 → 统计 → 图表（Statistics → Graphs）。

有 CPU、内存、接口流量、负载、WiFi 客户端数、Ping 延迟的长周期图表。

时间粒度：2 小时（30 秒精度）→ 1 天（5 分钟）→ 1 周（30 分钟）→ 1 月（2 小时）→ 1 年（1 天）。

> 重启后历史图表会丢一部分，因为 RRD 数据存在 `/tmp`（内存盘）。
> 这是有意为之，避免频繁写 flash 磨损存储。

## 改 CAKE 限速

默认 110Mbit 上/下行。学校实际套餐或信号变化时可能要调。

浏览器 → 网络 → SQM QoS → 改 "Download speed" 和 "Upload speed"（单位是 kbit/s）。

命令行：

```bash
uci set sqm.eth1.download='150000'   # 150Mbit
uci set sqm.eth1.upload='150000'
uci commit sqm
/etc/init.d/sqm restart
tc -s qdisc show dev phy1-sta0 | head -3   # 确认生效
```

**填多少合适**：填你实测峰值的 85-90%。填太高等于没限速（队列不生效），
填太低浪费带宽。实测值可以用 `curl` 下一个大文件看速度。

## 定时任务

```bash
cat /etc/crontabs/root
```

现在有两条：

```
*/5 * * * * /etc/campus_network/auto_login.sh     # 每 5 分钟检查认证
0 4 * * 1,4 /sbin/reboot                          # 每周一/周四凌晨 4 点重启
```

改完 crontab 要重启 cron 服务：

```bash
/etc/init.d/cron restart
```

> ⚠️ **绝对不要在 crontab 里写 `@reboot`、`@daily` 这类 `@` 关键字。**
> 这台路由器的 busybox crond 没编译这个功能，遇到 `@` 开头的行会直接崩溃退出，
> 而且 procd 会反复拉起它，进入崩溃循环——连 `*/5` 那条兜底认证也一起失效。
> 开机认证由 `/etc/init.d/campus_auth` 负责，不需要 crontab。

## 重启和关机

```bash
reboot          # 重启，约 90 秒恢复上网
poweroff        # 关机（之后要拔电源再插才能开机）
```

路由器已经配了每周一、周四凌晨 4 点自动重启。**不需要每天重启**，
频繁重启反而会因为信道扫描造成额外的断网。

## 恢复出厂设置

> ⚠️ 这会删掉所有配置，包括校园网账号。执行前先备份。

```bash
# 备份当前配置到电脑
ssh root@192.168.1.1 "sysupgrade -b /tmp/backup.tar.gz"
scp root@192.168.1.1:/tmp/backup.tar.gz .

# 清空并重启
firstboot -y && reboot
```

恢复备份：

```bash
scp backup.tar.gz root@192.168.1.1:/tmp/
ssh root@192.168.1.1 "sysupgrade -r /tmp/backup.tar.gz && reboot"
```

## 这台路由器还能干什么

装了但平时用不到的：

| 功能 | 在哪看 | 说明 |
|---|---|---|
| 广告拦截 | 服务 → Adblock | 18 万条规则，DNS 层面拦截，全设备生效 |
| WireGuard VPN | 网络 → 接口 → wg0 | 外网可进后台。改 `wg show` 看握手状态 |
| NTP 对时 | 系统 → 系统 → 时间同步 | 校园网断开时时钟可能不准 |

**注意内存**：这台机器只有 233MB 可用 RAM，平时剩 40-50MB。
别同时启用太多插件，尤其是带 Web 界面的（每个 LuCI 应用都要占内存）。

## 什么时候该看排障手册

下面这些症状，去 [排障手册.md](排障手册.md) 按症状查：

- 网页打不开 / 一直转圈
- 能 ping 通但网页被弹到登录页
- 手机连上 WiFi 但显示"无互联网"
- 整个路由器没反应
- 校内网站（教务、图书馆）打不开
- 认证日志里一直报错
