# 刷机指南：把原厂 AX3000T 刷成 ImmortalWrt

适用对象：拿到 `小米AX3000T刷机教程openwrt大分区版-干净原生.rar` 的人。
你不需要懂 Linux，按顺序做，每步都有"怎么确认成功了"。

预计耗时：40-60 分钟（其中 10 分钟是等待路由器重启）。

---

## 开刷之前，先确认三件事

### 1. 确认型号是 MT7981 版本

翻到路由器背面看标签，型号应该是 **RD03** 或 **RD23**。

如果是 **RD03v2**，**立刻停下**——那是高通 IPQ5018 芯片，和这份工具包完全不通用。

### 2. 确认固件批次和 NAND 厂商

刷完才知道自己属于哪批的话就晚了。两个办法：

- 生产日期在 2024 年之后的 V2 机型，NAND 可能是 Winbond 或 Foresee，需要用 24.10.1 以上的固件
- 本工具包里的固件是 **24.10.5**，覆盖全部三个批次（ESMT / Winbond / Foresee），不用挑

### 3. 准备一个地方存备份

备份文件加起来约 260MB。**建议同时放在电脑硬盘和一个 U 盘/网盘**。
这部分丢了，WiFi 校准数据就永久没了（后面第 3 步会解释）。

---

## 第 0 步：解压工具包

把 `小米AX3000T刷机教程openwrt大分区版-干净原生.rar` 解压到**一个短路径、纯英文或纯中文都可以但不要带特殊符号**的目录，例如：

```
D:\ax3000t\
```

解压后你会看到：

```
D:\ax3000t\小米AX3000T刷机教程openwrt大分区版-干净原生\
├── step1解锁ssh\
│   └── xmir-patcher-main\        ← 解锁 SSH 和刷固件的工具（自带 Python，不用另装）
│       ├── !START.bat             ← 双击这个启动
│       ├── firmware\              ← 放固件的目录（已经放好 initramfs 固件）
│       └── bootloader\            ← 只有 Redmi AC2100 的引导文件，AX3000T 用不到
├── step2刷入openwrt\
│   └── immortalwrt-24.10.5-...-squashfs-sysupgrade.bin   ← 正式系统固件
├── 恢复原厂系统\
│   ├── miwifi_rd03_firmware_48abd_1.0.98.bin              ← 小米原厂固件
│   └── MIWIFIRepairTool.x86.zip                            ← 小米官方救砖工具
└── 网络连接internet.bat           ← 打开 Windows 网络连接面板（快捷方式）
```

固件两个文件的区别，现在知道就行，后面会用到：

| 文件 | 大小 | 什么时候用 |
|---|---|---|
| `firmware\...initramfs-factory.ubi` | 14MB | **第一次刷**，从原厂系统换成 OpenWrt 时用 |
| `step2刷入openwrt\...squashfs-sysupgrade.bin` | 13MB | **已经在 OpenWrt 上了**，升级或重刷时用 |

## 第 1 步：连接电脑和路由器

1. 路由器**只插电源**，WAN 口留空
2. 网线一头插电脑，一头插路由器的 **LAN4 口**（不要插蓝色的 WAN 口）
3. 等 2 分钟，指示灯稳定常亮

**确认连上了**：浏览器打开 `http://192.168.31.1` 或 `http://miwifi.com`，
应该看到小米的管理登录页。

打不开的话，在命令行执行 `ipconfig`，看以太网适配器的 IPv4 是不是 `192.168.31.x`。
如果不是，检查网线，或者先关掉电脑的 WiFi（电脑可能优先走无线网卡）。

### 如果是全新机器

按小米的初始化向导走一遍，**设置一个管理密码并记住它**，后面要用。

### 如果忘了管理密码

用牙签按住 Reset 孔 10 秒以上，等指示灯闪烁，路由器恢复出厂后再按"全新机器"处理。

---

## 第 2 步：连接工具

双击 `step1解锁ssh\xmir-patcher-main\!START.bat`。

会弹出一个黑底命令行窗口，显示菜单：

```
==========================================================

Xiaomi MiR Patcher

==========================================================
 1 - Set IP-address (current value: 192.168.31.1)
 2 - Connect to device (install exploit)
 3 - Read full device info
 4 - Create full backup
 5 - Install EN/RU languages
 6 - Install permanent SSH
 7 - Install firmware (from directory "firmware")
 8 - {{{ Other functions }}}
 9 - [[ Reboot device ]]
 0 - Exit
```

**输入 `2` 回车**，按提示输入路由器管理密码。

> 输密码时屏幕上**一个字符都不会显示**（连 `***` 都没有）。这是正常的，输完直接回车。

**确认成功**：出现类似 `Connected`、`exploit` 成功的字样，或者显示出路由器的 STOK 令牌。

**失败怎么办**：检查密码是否正确、IP 是不是 `192.168.31.1`、网线是不是插在 LAN4。

---

## 第 3 步：备份全部分区（这一步不能省）

**输入 `4` 回车** → Create full backup。

工具会通过 SSH 读完整个 128MB 闪存，在 `xmir-patcher-main\backups\` 下生成十几个文件。耗时 2-5 分钟。

生成的文件里，有两个最重要：

| 文件 | 是什么 | 丢了会怎样 |
|---|---|---|
| `mtd4_Factory.bin` | **WiFi 校准数据** | 信号永久变差，无法恢复。每台机器的校准值都不一样，没有通用替代 |
| `mtd0_FULL_DUMP.bin` | 完整闪存镜像 | 相当于整机快照，最后一道保险 |

其余 `mtd1_BL2.bin`、`mtd5_FIP.bin`、`mtd3_Bdata.bin` 等也一并留着。

> **备份完立刻复制到 U 盘或网盘。** 工具包本身要传给下一个人，别指望它帮你保管。

**确认成功**：`backups\` 目录下有 13 个左右 `.bin` 文件，其中 `mtd0_FULL_DUMP.bin` 约 128MB。

---

## 第 4 步：解锁 SSH

**输入 `6` 回车** → Install permanent SSH。

这一步的原理：小米原厂固件其实内置了 SSH 服务（dropbear），只是默认关闭。
工具把启动脚本改掉，让它开机自动运行。

路由器可能会自己重启一次，等 1-2 分钟。

**确认成功**：另开一个命令行窗口，执行

```bash
ssh root@192.168.31.1
```

首次连接会问 `Are you sure you want to continue connecting?`，输入 `yes` 回车。
如果出现 `password:` 提示或者直接进了 `root@XiaoQiang:~#`，就成功了。

密码可能是空的（直接回车），也可能是你设的小米管理密码。两种都试一下。

---

## 第 5 步：刷入 ImmortalWrt

**回到工具窗口，输入 `7` 回车** → Install firmware (from directory "firmware")。

工具会自动读取 `firmware\` 目录里的 `immortalwrt-24.10.5-...initramfs-factory.ubi`，
上传到路由器并写入。过程中会打印解析到的镜像信息，看到 `Ready` 之类的字样就是完成了。

### 接下来发生的顺序

```
t=0s      开始写入
t=30s     写完，自动重启
t=30-90s  重启中，指示灯可能闪烁或熄灭
t=120s    启动完成
```

**这两分钟里绝对不要做**：断电、拔网线、按 Reset、反复开关电源。

> **为什么不能断电？** 写入的是系统分区。断电后需要进恢复模式重刷。
> 只要 BL2（mtd1）和 FIP（mtd5）没坏，路由器就能救回来，不会变砖——但会很麻烦。

---

## 第 6 步：验证刷机结果

等 3 分钟，然后依次验证：

**① 管理地址变了**

浏览器打开 `http://192.168.1.1`（**不是** 192.168.31.1 了）。
应该看到 LuCI 登录页——ImmortalWrt 的 Web 后台，中文界面。
用户名 `root`，密码留空，直接点登录。

**② SSH 能进**

```bash
ssh root@192.168.1.1
```

密码留空，直接回车。

**③ 分区大小对了**

```bash
df -h /overlay
```

看到 `Size` 在 50MB 以上就对了。如果只有 5-10MB，说明分区没扩起来。

**④ 系统版本对了**

```bash
cat /etc/os-release
```

应该显示 `NAME="ImmortalWrt"`、`VERSION="24.10.5"`。

四条全过，刷机成功。

---

## 第 7 步：立刻做三件安全事

刷完的系统是"毛坯房"：root 无密码、WiFi 无加密。先堵上再谈上网。

```bash
# 1. 设 root 密码
passwd

# 2. 给 2.4G 和 5G 都设上 WiFi 名和密码
#    此时 radio1 还是 AP 模式，直接改它。
#    后面配校园网时会把 radio1 改成 STA，届时会另建一个 AP 接口放热点。
uci set wireless.default_radio0.ssid='你的WiFi名'
uci set wireless.default_radio0.encryption='psk2'
uci set wireless.default_radio0.key='你的WiFi密码'
uci set wireless.default_radio1.ssid='你的WiFi名-5G'
uci set wireless.default_radio1.encryption='psk2'
uci set wireless.default_radio1.key='你的WiFi密码'
uci commit wireless
wifi reload

# 3. 确认改完了
uci show wireless | grep -E 'ssid|encryption'
```

> `psk2` = WPA2，兼容性最好。新设备才考虑 `sae`（WPA3）。

## 出问题了怎么办

### 刷完打不开 192.168.1.1

1. 再等 2 分钟（可能还在启动）
2. `ipconfig` 看电脑 IP 是不是 `192.168.1.x`
   - 还是 `192.168.31.x` → 路由器 IP 没变，可能没刷成功
   - 是 `169.254.x.x` → 没拿到 IP，检查网线
3. 网线换到 LAN1 口再试
4. 超过 10 分钟还不行，走下面的救砖流程

### 救砖：刷回小米原厂

用 `恢复原厂系统\` 里的东西：

1. 解压 `MIWIFIRepairTool.x86.zip`
2. 电脑网线接路由器 LAN 口
3. 按住 Reset 孔通电，等指示灯闪烁（进入恢复模式）
4. 运行修复工具，选 `miwifi_rd03_firmware_48abd_1.0.98.bin`
5. 等它刷完，路由器自动重启

> 这个固件是 1.0.98 版。刷回原厂后 WiFi 密码是初始状态，需要重新设置。

### 完全没反应（灯都不亮）

如果修复工具也连不上，说明 bootloader 也坏了。这种情况需要 TTL 串口 + 编程器，
普通人做不到，找会修路由器的人处理。**只要第 3 步的备份还在，数据是能恢复的。**

## 这一版工具包的一个缺口（需要知道）

`bootloader\` 目录里只有 Redmi AC2100 的三个引导文件（`uboot_r3g.bin`、`uboot_r3p.bin`、
`uboot_rm2100.bin`）和一个 Breed，**没有 AX3000T 专用的 U-Boot**。

所以第 5 步刷完之后，overlay 大小取决于原厂分区表。如果 `df -h /overlay` 只有 10MB 左右，
说明没扩成大分区，需要另外找 `mt7981_ax3000t-fip-fixed-parts.bin` 之类的
AX3000T 大分区 U-Boot 再刷一次。这个文件不在本工具包里。

> 本项目自用的两台路由器已经是大分区（78MB），`df -h /overlay` 显示约 58MB 可用。
> 如果你只是想装本项目的认证脚本，50MB 完全够用，不一定非要大分区。
