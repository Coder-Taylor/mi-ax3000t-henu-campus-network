# 这台路由器还能干什么

刷了 OpenWrt 之后它就是一台真正的 Linux 服务器。但它有硬限制：**无 USB 口、233MB 可用内存、约 58MB 可写空间**。

下面按"值不值得装"排序，每条都说清代价。

---

## 已在用

| 功能 | 怎么用 | 占多少资源 |
|---|---|---|
| 广告拦截 adblock | LuCI → 服务 → Adblock，18 万条规则 | 约 15MB 内存 |
| 流量监控 nlbwmon | LuCI → 服务 → 带宽监控 | 约 5MB |
| 性能图表 collectd | LuCI → 统计 → 图表 | 约 10MB |
| WireGuard 客户端 | LuCI → 网络 → 接口 → wg0 | 约 3MB |
| CAKE 流控 | LuCI → 网络 → SQM QoS | 无（内核模块） |
| 卡顿探针 | `/overlay/probe.log` | 无（每分钟一次 curl） |

---

## 值得装（确实有用）

### DNS over HTTPS — ⭐⭐⭐

**解决什么**：校园网的 DNS 会插广告、会返回错误 IP。加密 DNS 让查询内容别人看不到。

```bash
opkg update
opkg install https-dns-proxy luci-app-https-dns-proxy
```

装完在 LuCI → 服务 → HTTPS DNS Proxy 里启用，选 Cloudflare 或阿里的 DoH 地址。

**注意**：装完之后你原来那套 DNS 四层修复（hosts + 分流）依然生效，
DoH 只是替代了"问上游"这一段。如果校内网站突然打不开，先关掉 DoH 试试。

**代价**：约 8MB 内存，每个查询多 10-20ms 延迟。

### 访客网络 — ⭐⭐

**解决什么**：给来串门的人一个单独 SSID，隔离在你内网之外，看不到你的设备也进不了路由器后台。

LuCI → 网络 → 无线 → 添加。要点：

- 建一个新的 AP 接口，绑到 `guest` 网络（不要绑 `lan`）
- 新建 `guest` 接口（`proto=none`，静态 IP 如 `192.168.2.1`）
- 防火墙新建 `guest` 区，`input=REJECT`、`forward=REJECT`，只允许 `guest → wan`
- 加一条转发规则 `guest → wan`

**代价**：内存几乎不涨。这是性价比最高的一项。

## 有条件才装

### DDNS 动态域名 — ⭐⭐

**解决什么**：用域名代替 IP 访问路由器，不用记数字。

**但对这个项目没用**。校园网给的是 `10.x.x.x` 私有地址，外面根本路由不到。
除非你同时开着 WireGuard 且服务器能转发，那还有一点意义。

想装：`opkg install ddns-scripts luci-app-ddns`，配合 duckdns 之类的免费服务。

### 透明代理 / 软路由分流 — ⚠️

**技术上能做，实际不建议**。

- 233MB 内存跑代理客户端 + 分流规则表，经常 OOM
- 校园网出口本来就只有 100Mbps，直连完全够
- 配置复杂，出问题整个宿舍断网，排查困难

**如果一定要**：先把 adblock 和 collectd 停掉腾内存，然后只装最轻量的方案。

> 请遵守当地法规和学校网络使用规定。

## 装不了

### 文件共享 NAS — ❌

**没有 USB 口**，也没有 microSD 槽位。128MB Flash 里能写就 58MB，存不了一部电影。

需要 NAS 的话：换带 USB 的路由器（AX6000 之类），或者用旧电脑/树莓派。

### 打印机服务器 — ❌

同样卡在没 USB 口。

### DLNA 媒体服务器 — ❌

`minidlna` 能装，但没有地方存媒体文件。

### Docker — ❌

233MB 内存跑不动。OpenWrt 自己就占 180MB 左右，Docker 守护进程本身就要 100MB+。

### IPv6 公网访问 — ⭐

**取决于校园网**。目前这台路由器只有内网 ULA 地址（`fddd:ec86:845a::/60`），
没有全局 IPv6、没有 v6 默认路由。也就是说校园网压根没给 IPv6 出口。

如果哪天学校开了 IPv6，先确认 `ip -6 route` 里有 `default`，再考虑。

## 资源现状（实测）

```
CPU:   双核 A53 1.3GHz，日常负载 < 0.2
RAM:   总 233MB，系统占 131MB，可用 40-50MB
Flash: overlay 约 58MB 可用
```

**还能玩的**：

- 装几个轻量 opkg 包（58MB 够装很多）
- 跑 shell 脚本、定时任务
- 学 Linux / 网络 / 防火墙（这是它最擅长的事）
- 搭个极简 Web 页面

**别指望的**：

- 大文件存储
- 高并发服务
- 重型容器
- 高负载 VPN（CPU 会吃满）

## 装东西的通用流程

```bash
# 1. 更新软件源
opkg update

# 2. 搜一下有没有
opkg search 关键词

# 3. 装
opkg install 包名

# 4. 装完检查内存
free -m

# 5. 如果不满意，卸掉
opkg remove 包名
```

**装之前先看内存**。每次装完都跑一次 `free -m`，available 掉到 20MB 以下就不要继续装了。

**装了 LuCI 界面的插件尤其吃内存**（每个都要起一个 uhttpd 子进程）。
纯命令行工具（比如 `curl`、`nmap`）几乎不占常驻内存。

## 停掉不需要的服务

```bash
# 看所有服务状态
/etc/init.d/      # ls 一下才知道有什么
for s in /etc/init.d/*; do printf "%-30s %s\n" "$(basename $s)" "$($s enabled && echo enabled || echo disabled)"; done

# 停掉并禁止开机自启
/etc/init.d/服务名 stop
/etc/init.d/服务名 disable
```

能安全停掉的候选：`uhttpd`（不用 Web 后台时）、`collectd`（不看图表时）、
`adblock`（不想要广告拦截时）。

**不要停**：`network`、`firewall`、`dnsmasq`、`dropbear`（否则 SSH 也进不去了）。
